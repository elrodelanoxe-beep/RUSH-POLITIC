# Optimización

> Contenido extraído del [GDD v0.1](../01_CONCEPTO/GAME_DESIGN_DOCUMENT.md) (secciones 13 y 15). El GDD es la fuente de referencia; si hay diferencias, prevalece el GDD.

## Consideraciones técnicas

Será importante implementar:

- Object Pooling para enemigos y proyectiles.
- Sistemas de generación de oleadas.
- Gestión eficiente de animaciones.
- Optimización de modelos 3D.
- Control de memoria.
- Gestión de colisiones.
- Sistema modular de armas.
- Sistema configurable de dificultad.
- Guardado de progresión.

## Equilibrio gráfico y rendimiento

La calidad gráfica deberá equilibrarse con el rendimiento para garantizar una experiencia fluida en dispositivos móviles (sección 13). Principio del proyecto: rendimiento estable en móviles (sección 18).
